# 小白常见问题

[上一章：安全](08-security.md) · [返回首页](../README.md)

## 0.06 倍率是不是每问一次只扣 0.06 元？

不是。它表示基准费用乘 0.06。请求越长、输出越多或模型基准价越高，实际费用仍可能增加。完整解释见[倍率章节](02-multiplier.md)。

## 充值 10 元能问多少次？

没有固定答案。要看模型、分组倍率、输入输出长度、历史上下文和计费模式。最可靠的方法是用三到五次典型任务测试，然后根据使用记录估算。

## 有 ChatGPT 或 Claude 订阅，还要单独充值吗？

通常要。官方网页/App 订阅、官方 API 和中转站余额是不同产品和计费体系，不能默认互通。

## 0.06 分组能用哪些模型？

平台当前提供 0.06 倍率 ChatGPT 分组，并展示 GPT-5.6 Sol、GPT-5.6 Terra 等模型；平台也展示 Claude Fable 5。模型、分组、ID、倍率和可用性会变化，请在每次配置前以控制台为准。

## API Key 是登录密码吗？

不是账户登录密码，但同样敏感。它让客户端代表你的账户调用接口并产生费用，因此不能公开。

## Base URL 到底填哪个？

- 普通 OpenAI 兼容客户端一般填 `https://www.fastaitoken.com/v1`。
- 如果客户端明确说明会自动追加 `/v1`，则填 `https://www.fastaitoken.com`。
- 本指南中的 Codex Responses 示例按 FastAiToken 文档填写不带 `/v1` 的地址。

关键是最终请求路径不能重复成 `/v1/v1`。

## 模型名称应该填 GPT-5.6 Sol 吗？

不一定。宣传或页面展示名称不总是实际 API 模型 ID。请从控制台或模型列表复制当前准确 ID，注意大小写、连字符和版本后缀。

## 为什么短问题也用了不少 Token？

客户端可能同时发送系统提示、历史对话、工具说明、项目文件或其他上下文。你看到的一句话不一定是请求的全部内容。

## 一次失败请求会扣费吗？

视失败发生在哪个阶段和平台规则而定。查看使用记录最准确。避免让客户端无限自动重试；发现连续失败时先暂停排查。

## 能把 API Key 给朋友一起用吗？

不建议。你无法清楚区分费用和操作，也增加泄露风险。每个人应使用自己的账户和 Key。

## Codex 会不会改坏项目？

Codex 能读取、修改文件并运行命令，取决于你的授权和任务要求。重要项目应使用 Git，先让 Codex解释计划或做只读检查，确认差异后再提交；不要在没有备份的目录测试删除或批量修改。

## 中转站安全吗？

不能仅凭“能用”判断安全。中转站在技术路径上会接收请求，应评估运营主体、隐私政策、服务条款、日志规则和自己的数据敏感程度。机密数据应采用符合组织要求的正式方案。
