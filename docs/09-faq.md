## 💰 一、算钱与充值篇

### Q1：`0.06 倍率` 是不是我每问一次就固定扣 0.06 元？
**不是。** `0.06 倍率` 的意思是**“打 0.6 折（实际扣费 ≈ 模型原价 × 0.06）”**。
- 如果你只问一句短短的话，模型原价可能只有几厘钱，打完 0.6 折后连 1 分钱都不到；
- 如果你发了一篇几万字的长文或让 Codex 连续改代码，模型原价变高了，乘完 0.06 之后也可能是几分钱或几毛钱。详见 [02. 倍率章节](02-multiplier.md)。

### Q2：充值 10 元到底能问多少次？
**没有固定次数**，因为它取决于你选的模型贵不贵、所属分组倍率是多少、每次提问和回答有多长、以及有没有带着长长的历史记录。
最靠谱的估算办法：选好你的常用模型和优惠分组，按平时习惯聊 3~5 次，去控制台「使用记录」看一眼平均每次扣几分钱，一除就知道 10 元大概能用几百次还是几千次了。

### Q3：如果我充值后发现不会配，或者余额用不完，能退款吗？
根据 [FastAiToken 官方价格说明](https://docs.fastaitoken.com/docs/pricing)，平台支持 **30 天无理由退款**：充值后 30 天内，**未使用的账户余额支持原路退回（微信 / 支付宝免手续费）**。不过已消耗的调用额度通常不支持退款，因此我们始终建议新手先小额充值或联系客服了解新用户福利体验，跑通确认满意后再按需充值。

### Q4：我已经买了 ChatGPT Plus 或 Claude Pro 官方网页会员，在软件里用中转站还要单独充值吗？
**要的。** 官方网页/App 包月会员、官方直连 API、以及中转站 API 是完全独立的三套计费体系，余额互不相通。详见 [01. 什么是中转站中的对比表](01-what-is-a-relay.md)。

### Q5：为什么我只发了短短一句话，后台却显示消耗了好几千 Token？
大概率是因为你**在一个已经聊了很久的对话窗口里继续提问**（或者软件自带了很长的系统提示词/自动读取了项目代码文件）。客户端可能再次携带部分或全部历史，实际还会受历史条数、摘要、裁剪和缓存计费影响。**省钱绝招**：换一个新话题时，随手点客户端里的 **「新建对话」**！详见 [03. 计费章节](03-billing.md)。

## ⚙️ 二、软件配置篇

### Q6：`0.06 倍率` 优惠分组能用哪些模型？怎么才能用上？
目前平台提供 0.06 倍率 ChatGPT 分组，按平台当前规则展示 GPT-5.6 Sol、GPT-5.6 Terra、GPT-6.1 Sol 等模型，同时平台也提供 Claude Fable 5 及 Claude Kiro 等分组与模型。
**想用上优惠分组，有两个动作缺一不可**：
1. 在 [API 密钥页面](https://www.fastaitoken.com/keys) 创建或编辑你的 API Key 时，把 **「分组」** 选为对应的优惠分组；
2. 去控制台「可用渠道 / 模型广场」查看该分组当前支持哪些模型，并**复制准确的模型 ID** 填进客户端。

### Q7：`Base URL（接口地址）` 到底填带 `/v1` 的还是不带 `/v1` 的？
- **普通聊天/翻译客户端（如 Chatbox、Cherry Studio、Cursor 等）**：一般填 `https://www.fastaitoken.com/v1`（如果软件输入框下方有灰色预览地址，确保最终预览是 `https://www.fastaitoken.com/v1/chat/completions`，不要变成 `/v1/v1`）。
- **OpenAI Codex 终端助手（Responses 协议）**：在 `config.toml` 里填 `https://www.fastaitoken.com` **（不带 `/v1`）**。
详见 [06. 客户端配置速查表](06-client-config.md)。

### Q8：软件里的「模型名称 / Model ID」直接填 `GPT-5.6 Sol` 可以吗？
**千万别自己手打展示名称！** 海报或网页上的宣传名（如 `GPT-5.6 Sol`）往往不是代码接口认的真实 ID（真实 ID 可能是全小写带连字符的格式，比如 `gpt-6.1-sol`）。请一定去控制台模型列表**点击复制准确的模型 ID**，原样粘贴进软件。

### Q9：我在 Windows 上给 Codex 建好了 `auth.json` 和 `config.toml`，为什么打开 Codex 还是让我登录 OpenAI 官方账号？
可能是隐藏扩展名导致文件实际叫 `auth.json.txt` / `config.toml.txt`，也可能是目录、服务商选择或配置解析问题。
先按 [05. OpenAI Codex 章节](05-openai-codex.md) 核对真实文件名和实际目录，再备份并修正。已有配置优先用 B2 手动合并；B1 脚本遇到已有文件会备份并停止，不直接覆盖。

### Q10：一次失败报错的请求会扣我的钱吗？
通常像密钥填错（401）、模型名字填错（404）这类在门口就被拦下的请求不会产生模型扣费，具体以控制台「使用记录」为准。但要注意：**如果客户端开启了“失败自动无限重试”，或者上游已經生成了部分内容才中断，可能会产生消耗**。因此看到报错时请先暂停排查，不要让软件在后台一直自动重试。

## 🛡️ 三、安全与进阶篇

### Q11：API Key 是我的网站登录密码吗？能不能借给朋友一起用？
- 它**不是**你登录 FastAiToken 网页的密码，但它是**直接绑定你钱包余额的消费凭证**。
- **强烈不建议**把同一把 Key 借给朋友共用，或者在所有软件里都填同一把 Key。如果你确实想临时给某台设备用，请单独新建一把 Key，并设好明确的「额度上限」和「过期时间」，用完随时删掉。

### Q12：OpenAI Codex 会不会不小心改坏我电脑里的文件？
Codex 的确拥有读写当前目录文件和运行命令的权限。为了安全起见：
1. 重要项目务必使用 Git 管理，或者在让 Codex 大改前手动复制备份一份文件夹；
2. 第一次在某个文件夹使用或下达复杂指令时，可以先在提示词末尾加上一句：`请先只列出修改计划，不要直接修改或删除任何文件，等我确认后再执行`。

### Q13：中转站安全吗？有什么东西是不能发给它的？
从技术路径上，任何中转服务都需要先接收你的请求才能转发给模型。虽然 [FastAiToken 官方文档](https://docs.fastaitoken.com/docs/) 说明采用透明代理、不留存对话内容，但无论使用哪家平台，都请守住安全底线：**不要在对话里发送密码、身份证号、银行卡信息、服务器私钥、未脱敏的客户隐私或公司核心机密**。详见 [08. 安全须知](08-security.md)。
