## 一、用“点外卖”秒懂中转站是怎么工作的

很多刚接触 AI 的朋友会懵：“我已经下了 Chatbox 或安装了 Codex，为什么打开却不能直接说话？”

因为 **Chatbox、Cherry Studio、Codex 这些软件只是“空壳工具（好比手机上的外卖 App）”**，它们本身不生产 AI 回答，需要连接到背后的 AI 大模型才能干活。

而 **FastAiToken 这类中转站（也叫 API 网关 / 聚合平台）**，就相当于一家集合了各家名厨的**统一前台**：

```text
【你的客户端软件】 ──(带上 API Key 钥匙，发往 Base URL 地址)──► 【FastAiToken 中转站】 ──► 【GPT / Claude / Gemini 等不同模型】
【你在屏幕上看到回答】 ◄─────────────(原路返回生成结果)───────────── 【按分组倍率结算扣费】 ◄──
```

你不需要为每一家 AI 公司单独注册账号、单独绑卡充值，只要把软件连到这个“统一前台”，想换哪个模型，改一下菜品编号（模型 ID）就行。

## 二、三种用 AI 的方式有什么区别？（新手必看对比）

很多小白分不清“官网包月会员”“官方 API”和“中转站 API”，下面这张表帮你彻底理清：

| 对比维度 | 1. 官方网页/App 包月会员<br>（如 ChatGPT Plus / Claude Pro） | 2. 官方直连 API<br>（OpenAI / Anthropic 开发者平台） | 3. FastAiToken 中转站 API<br>（本指南介绍的方式） |
| --- | --- | --- | --- |
| **怎么付钱？** | 按月固定交月租（比如每月 $20），不管这月用多用少都扣这么多。 | 用多少付多少（按 Token 计费），通常需绑定海外信用卡。 | **用多少付多少**（支持国内常见支付方式充值，按平台分组倍率计费）。 |
| **能在哪里用？** | 只能在官方自己的网页、桌面端或手机 App 里聊天。 | 可填入 Chatbox、Codex、沉浸式翻译等第三方软件。 | **同样可填入 Chatbox、Codex、Cherry Studio、Cursor 等各种支持自定义接口的软件**。 |
| **能用哪些模型？** | 只能用该厂商自己旗下的模型（买 OpenAI 就不能用 Claude）。 | 只能调用该厂商自己的模型，换厂商得换账号和密钥。 | **一个入口切换多家主流模型**（OpenAI、Claude、Gemini、国产模型等）。 |
| **适合什么人？** | 每天只在网页端高频聊同一种模型的用户。 | 有海外支付条件、只用单一厂商接口的开发者。 | **想在第三方客户端/编程工具里灵活换模型、希望按量付费或使用低倍率分组的用户**。 |

> [!IMPORTANT]
> **重要提醒**：这三套体系的钱是**互不相通**的！就算你已经买了 ChatGPT 官方网页会员，在第三方软件里调用 API 时仍然需要单独的 API 余额；反过来，在中转站充的余额也是用来给 API 客户端扣费的，不等于开通了官方网页会员。

## 三、配软件时一定会遇到的 4 个词

下面 4 个词能帮助你理解大多数自定义接口的配置；各软件仍以自己的当前文档为准：

### 1. 客户端（Client）—— 你手里操作的软件
比如用来聊天的 **Chatbox**、**Cherry Studio**，用来翻译网页的 **沉浸式翻译**，或者在终端里帮你写代码的 **OpenAI Codex**、**Claude Code**。中转站负责提供后台接口，客户端负责给你提供好看的操作界面。

### 2. Base URL（接口地址 / API Host）—— 请求寄往哪里的收件地址
告诉客户端把你的问题发送到哪个服务器。
- **普通 OpenAI 兼容客户端（最常见）**通常填：
  ```text
  https://www.fastaitoken.com/v1
  ```
- **OpenAI Codex（Responses 协议）**或明确提示“会自动补全 `/v1`”的软件则填：
  ```text
  https://www.fastaitoken.com
  ```
- **避坑口诀**：地址不能少字母、首尾不能有空格，最终发出的请求里绝对不能出现重复的 `/v1/v1`。

### 3. API Key（令牌 / 密钥）—— 你的门钥匙 + 消费付款码
在 FastAiToken 控制台创建的一串以 `sk-` 开头的字符。客户端每次发消息都会出示这把钥匙，平台认钥匙不认人——**谁拿到了你的 API Key，谁就能直接花你账户里的余额**。所以千万不要截图发群、不要发给陌生人、更不要上传到公开的 GitHub 仓库。

### 4. 模型 ID（Model ID）—— 实际干活的 AI 编号
不同模型在写代码、写文章、反应速度和价格上各有所长。
- **特别注意**：网页宣传图上写的名字（比如 `GPT-5.6 Sol`）叫“展示名称”，而填进软件里的往往是严格区分大小写和连字符的**“模型 ID”**（比如 `gpt-6.1-sol`）。配置时一定要从控制台模型列表里**复制粘贴**，不要自己手打猜名字。

## 四、中转站安全吗？它会看到我的对话吗？

我们要客观、透明地看待这个问题：

1. **为什么有人选择 FastAiToken？**
   根据 [FastAiToken 官方文档中心](https://docs.fastaitoken.com/docs/) 与 [价格说明](https://docs.fastaitoken.com/docs/pricing) 披露的服务承诺，平台主打：
   - **纯官转与模型保真**：强调不降智、不偷换模型，保真度可验证；
   - **30 天无理由退款**：充值后 30 天内，**未使用余额支持原路退回**（微信/支付宝免手续费），对新手小额试错非常友好；
   - **数据透明代理**：官方说明采用透明代理、不留存对话内容、最小化日志。
2. **作为用户，你必须守住哪些安全底线？**
   从网络技术原理上讲，任何中转站都必须先接收你的提问内容，才能帮你转发给上游模型。因此，无论平台口碑如何，都建议养成良好的安全习惯：
   - **绝不发送个人核心隐私**：不要把银行卡密码、身份证正反面、验证码、家庭住址发给 AI；
   - **绝不发送机密凭证**：不要把未公开的商业机密、客户隐私名单、服务器 SSH 私钥或生产环境数据库密码直接发进对话；
   - 如果用于公司正式业务，请先仔细阅读平台现行服务条款与隐私政策，确认符合所在机构的合规要求。
