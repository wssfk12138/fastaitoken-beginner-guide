# 什么是中转站

[返回首页](../README.md) · [下一章：倍率](02-multiplier.md)

## 先说结论

AI 中转站也常被叫作“API 中转”“AI 网关”或“聚合平台”。它在你的软件和模型服务之间负责接收、转发请求，并根据平台规则结算费用。

可以把它想成商场的统一服务台：

```text
你使用的客户端 → 中转站 → 不同的 AI 模型
                 ← 回答结果 ←
```

你不需要让每个客户端分别对接许多厂商，只需填写中转站提供的地址和 API Key，就可能在同一个入口选择多种模型。

## 为什么有人使用中转站

常见原因有：

- 一个账户下管理不同模型，切换更方便。
- 许多客户端只需更换 Base URL 和 API Key 就能接入。
- 平台可能提供不同倍率、套餐或计费分组。
- 统一查看余额和使用记录。

这并不表示中转站一定适合所有人。它多了一层服务方，也就多了一层对稳定性、隐私和平台规则的依赖。涉及敏感数据或正式业务时，需要认真阅读服务条款并评估风险。

## 四个一定会遇到的词

### Base URL：收件地址

Base URL 告诉客户端把请求送到哪里。FastAiToken 的普通 OpenAI 兼容地址是：

```text
https://www.fastaitoken.com/v1
```

地址少一个字、多一个空格或重复写成 `/v1/v1`，都可能请求失败。

### API Key：钥匙和消费凭证

API Key 通常以 `sk-` 开头。客户端每次请求都会带上它，平台据此识别账户和扣费。

它不像普通昵称，而更像银行卡密码。不要截图公开，不要写进 README，也不要发给陌生人。

### 模型：实际干活的 AI

模型是处理任务的 AI。不同模型在编程、写作、速度、上下文长度和价格方面可能不同。客户端里填写的是平台当前支持的“模型 ID”，不能只凭宣传名称猜写法。

### 客户端：你操作的工具

Chatbox、Codex、支持自定义接口的编辑器插件等，都属于客户端。中转站本身不是这些客户端；它提供的是客户端要连接的服务入口。

## 中转站会看到什么

从技术路径上看，中转服务需要接收你的请求才能转发，因此可能接触：

- 你发送的提问和文件内容
- 模型返回的结果
- API Key 对应的账户、时间和用量信息
- IP 地址及必要的服务日志

所以不要通过中转站发送密码、私钥、身份证、未公开源码、客户资料或公司机密。具体记录范围、保存时间和使用方式，应以平台隐私政策与服务条款为准。

## 它和官方订阅是一回事吗

不是。

- ChatGPT、Claude 等网页或 App 订阅，通常服务于对应的官方产品。
- API 使用通常按请求量或 Token 单独计费。
- 中转站余额一般也不能等同于某个官方网页订阅权益。

即使平台描述某个分组来自某类订阅或资源池，你在客户端里使用的仍是平台提供的 API 服务，应按平台当前计费和可用性来理解。
