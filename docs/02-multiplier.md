# 倍率到底是什么意思

[上一章：中转站](01-what-is-a-relay.md) · [返回首页](../README.md) · [下一章：计费](03-billing.md)

## 一句话解释

倍率是计费时乘在基准费用上的系数。

```text
实际费用 ≈ 基准费用 × 倍率
```

例如某次使用按基准价计算是 1 元：

| 分组倍率 | 估算实际费用 |
| --- | ---: |
| 1 倍 | 1 元 |
| 0.5 倍 | 0.5 元 |
| 0.1 倍 | 0.1 元 |
| 0.06 倍 | 0.06 元 |

如果基准费用是 10 元，0.06 倍率就是约 `10 × 0.06 = 0.6 元`。

## 最重要的误区

**0.06 倍率不等于每次请求固定收费 0.06 元。**

短短一句话和让模型阅读大量代码再生成长文，消耗的 Token 不同，基准费用自然不同。倍率只负责把这笔基准费用按比例缩放。

可以把它想成商场打折：六折是原价乘 0.6；0.06 倍率则是基准费用乘 0.06。但首先得知道“原价”是多少。

## 为什么同样是 0.06 倍率，扣费仍不同

因为倍率只是公式中的一个数，还可能受这些因素影响：

- 选用的模型基准单价不同。
- 输入和输出 Token 数量不同。
- 输入与输出的单价可能不同。
- 缓存 Token、图片、音频或工具调用可能有独立规则。
- 有些能力按次收费，不按 Token 收费。
- 分组可能只适用于部分模型。

所以比较价格时，不能只看“倍率最低”，还要看模型原始价格、分组规则和自己的实际用量。

## 0.06 倍率分组怎么理解

FastAiToken 当前提供 0.06 倍率 ChatGPT 分组，并按平台当前规则展示 GPT-5.6 Sol、GPT-5.6 Terra 等模型；平台也展示 Claude Fable 5 等模型。

这句话包含四个必须保留的边界：

1. 倍率通常属于某个特定分组，不一定适用于全站模型。
2. 模型可用性、名称和 ID 可能变化。
3. 某个分组繁忙、限速或维护时，使用体验可能变化。
4. 最终扣费以平台实时账单为准，而不是本教程里的示例。

使用前请在控制台核对：所选模型是否属于目标分组、输入和输出单价、倍率、限额，以及当前余额。

## 怎么避免意外扣费

第一次使用时采用“小额、短问题、看账单”的办法：

1. 充值或准备少量余额。
2. 创建一枚专门用于测试的 API Key，并设置额度限制（如果平台支持）。
3. 选择目标分组和一个当前可用模型。
4. 只发送一句短问题。
5. 到使用记录中核对模型、Token、倍率和实际扣费。
6. 确认无误后再进行长对话或大型代码任务。
